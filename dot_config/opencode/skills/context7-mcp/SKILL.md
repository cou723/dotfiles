# context7-mcp

ライブラリ・フレームワーク・APIリファレンスの質問や、コード生成にライブラリの使用方法を尋ねられた際に使用するスキルです。

## 反応する状況

以下の状況でこのスキルを有効活用してください:
- ライブラリ・フレームワークの使用方法を尋ねられた場合（例: "ReactのuseEffectの使い方を教えて"）
- APIリファレンスの質問（例: "Express.jsのrouterの使い方"）
- コード生成で特定のライブラリを使用する場合
- セットアップや初期化方法の質問

## 活用方法

1. **質問内容を整理**
   - 使用したいライブラリ・フレームワーク名
   - 具体的な質問内容や実現したい機能
   - 使用している言語やバージョン

2. **context7-mcp を使用**
   - `skill: context7-mcp` を含めて質問する
   - 具体的な質問内容を明確に伝える

3. **得られた情報を活用**
   - 提示された情報が正確か検証する
   - 必要に応じて追加質問を行う

## 注意事項

- context7-mcp は情報提供のみで、実際のコード実行は行いません
- 提示されたコードは動作確認が必要です
- バージョンや環境によって動作が異なる場合があります
